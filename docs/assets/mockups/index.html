ZZaiOrder・消費者端點餐

設計參考原型

靜態 HTML／CSS／原生 JS，供設計與前端確認視覺方向；不是正式產品程式碼（正式專案之後以 React 實作）。白底簡約、單一可換品牌色，適用小吃、飲料、咖啡、早餐、便當、火鍋等不同餐飲業。

單一品牌主色・7 組可換 四種資料完整度：full／mixed／noimg／minimal 商品卡：grid／list 全程免登入・登入僅為可略過的提示 單鍵快速鍵預設關閉・偵測到實體鍵盤後提醒開啟 點餐記憶與一鍵再點 結帳送出時最終確認庫存與時段 觸控面板（Kiosk）模式

直接以瀏覽器開啟本頁即可（不需伺服器）。device=mobile 在桌機視窗會以 390px 寬的 iframe 預覽（不加手機外框）；實際版型由 CSS media query 決定（≥768px 桌機版型、≥1024px 右側常駐訂單面板）。商品「圖片」皆為 emoji，不引用任何外部資源。

設計重點

白底與灰階層次

文字層次靠字重與灰階；只有一個品牌主色，不寫死任何業態的元素。

圓角與膠囊

卡片 16px；分類標籤、按鈕、徽章為膠囊；選取態為品牌淺底＋品牌色邊框＋品牌文字色。

無圖也整齊

GRID 無圖用佔位圖塊維持節奏；LIST 無圖不留縮圖欄；精簡資料每張卡只剩「品名」與「價格 … ＋ 加入」兩列。

觸控與對比

觸控目標 ≥ 44×44（觸控面板 ≥ 56×56）；一般文字 ≥ 4.5:1；危險／錯誤固定用 danger，附圖示與文字。

鍵盤優先也能點餐

方向鍵移動、Tab 順序等於視覺順序；單字元快速鍵預設關閉、偵測到實體鍵盤後才提醒開啟，不在輸入框 / 組字中觸發；徽章不改變可存取名稱。

提醒不位移版面

鍵盤提醒是不佔流的浮動卡：不搶焦點、不推擠操作區，不遮住取得焦點的元件；收起後在 ⌨ 上留下小圓點（手機沒有 ⌨，直接收起）；⌨ 入口（含結帳與訂單追蹤）、頁尾連結與購物車「移除」不依賴徽章開關。

送出時才最終確認

結帳頁首以預留高度（min-height）的狀態列說明「確認中 / 可供應 / 有 n 項需要調整」，明細行預留狀態槽，狀態變化不推擠送出鈕；被退回或按「查看」時才就地展開異動清單，一次列出全部問題與動作。

跟上次一樣

商品卡顯示「上次：…」與「↻ 再點」；選項失效時改為開啟面板並提示，不在使用者不知情下加入。
